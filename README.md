# 2027 护考 · 随机模拟测验

手机端可直接作答的护考模拟测验，每次进入自动抽一套新卷。

**在线地址：https://chenzhangsheng55-stack.github.io/test/**

## 限时

全卷限时 **30 分钟**，顶栏倒计时，剩 5 分钟转红，归零自动交卷并出分。时长改 `site/index.html` 里的 `EXAM_MINUTES` 一个常量即可。

这条同时是**唯一对截屏搜题真正有效的手段**：截屏搜一道题要 15～30 秒，30 道题在限时内搜不完。

## 防作弊

答题期间做了三件事：

- **离开答题界面即计次**，回到本页时弹出警告，**累计 2 次自动交卷**，成绩页记录次数
- **题干与选项禁止选中、复制、右键**，堵掉"长按复制 → 粘贴到搜题 App"这条路（填空输入框不受影响）
- 检测覆盖两类信号：`visibilitychange` 抓切换应用、锁屏、切标签页；`blur`/`focus` 抓页面仍可见但焦点被抢走的情况 —— **搜题悬浮窗、分屏小窗**属于后者

两类信号对同一次离开会同时触发，用标志位去重；再用 400ms 延迟过滤瞬时失焦，避免误判。

能力边界：浏览器没有阻止用户切换应用的权限，做的是"检测 + 惩罚"而非物理拦截；**从不抢焦点的纯绘制悬浮球（只截屏那种）任何网页都探测不到**，需要真正的防作弊只能上原生考试客户端。次数上限在 `index.html` 的 `SWITCH_LIMIT` 常量中调整。

## 怎么加题

### 选择题

在任意 `site/bank-mcq-*.js` 的数组里加一行，**正确答案固定写在第一个位置**（`a:0`），页面会在每次组卷时随机打乱选项顺序：

```js
{c:"章节标签",q:"题干",o:["正确答案","干扰项","干扰项","干扰项","干扰项"],a:0,e:"解析"},
```

### 填空大题

在 `site/bank-fill.js` 里加一条。`q` 中用四个下划线 `____` 表示空位，`a` 按顺序给出每个空的可接受答案，**同一个空的多种写法都列进去**（判分时还会自动忽略全角/半角、`~` 与 `-`、空格、单位和 `℃`/`°`/`%` 的差异）：

```js
{c:"章节", t:"小标题",
 q:"正常成人脉率为____次/分，呼吸为____次/分。",
 a:[["60~100"],["12~20"]]},
```

空位数量必须与答案组数一致，否则 CI 会直接拦下不予部署。每题固定 8 分按空均摊，写 8 个空就是每空 1 分。

## 部署

推送到 `main` 分支即自动部署，由 `.github/workflows/deploy.yml` 完成：先跑题库校验，通过后把 `site/` 打包发布到 GitHub Pages。校验不通过则不会发布，线上保持上一个可用版本。
